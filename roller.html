Console Access

You can still call functions directly from browser console:

  • rollString("2d6+5") - Roll a single expression
  • rollDice(20, 5) - Single die roll
  • rollDices(3, 6, 0, 2) - Multiple dice with bonuses
  • rollAction(rollObject["Tamiti"]["Axe Throw"]) - Roll all actions for a character
