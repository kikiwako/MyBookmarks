Dice Roller Reference

  • pad(value, length) - Center-aligns text
    Example: pad("Tamiti", 20) → " Tamiti "
  • rollDice(faces, bonus) - Single die roll
    Example: rollDice(20, 5) → random(6-25)
  • rollDices(number, faces, flatBonus, perDieBonus) - Multiple dice
    Example: rollDices(3, 6, 0, 2) → 3d6 where each die gets +2
    Note: flatBonus applies once to total, perDieBonus applies to each die
  • rollString(expression) - Parse dice notation
    Example: rollString("1d20+10-3") → roll and calculate
  • rollAction(object) - Roll all actions for a character
    Example: rollAction(rollObject["Tamiti"]["Axe Throw"])
